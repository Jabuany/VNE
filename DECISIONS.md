# Decisiones de VNE

## Plataformas objetivo · 2026-11-22

El usuario aprobó limitar VNE a Android y Linux y retirar Windows del alcance. El cambio elimina la necesidad de mantener una cadena de compilación, un adaptador y pruebas para Windows. Los runners, la distribución y la matriz de compatibilidad cubrirán Android y Linux.

## Contratos del Core · 2026-11-22

La autorización para avanzar al BLOQUE 6 cerró el punto de control de los contratos del Core. Se adoptó la API 1.0 con sesiones Dart tipadas, transporte interno por adaptador, capacidades opcionales y compatibilidad por versión de API, plataforma y arquitectura.

## Primer reproductor HTML5 · 2026-11-22

La autorización del BLOQUE 10 confirmó Android como primera plataforma. Se usa una Activity nativa con el WebView del sistema, aislamiento por perfil y un origen local por juego. La activación de desarrollo se limita a una compilación explícita sin permiso de Internet. La distribución y la implementación de Linux conservan sus puntos de control.
